# measurement only.

# * Open inputs
# - Bearing friction torque: spin-down test of bare body (both bearing pairs);
#   verifies PHY-05. Sim assumes 1.0 mN·m Coulomb, 1.2 mN·m breakaway.
# - Body moment of inertia: from CAD once layout exists. Sim estimate
#   2.0e-3 kg·m²; CTR-02 still met at ×1.75.
# - Wheel: sized by sim (sizing_sweep): inertia 1.2e-4 kg·m² (brass disc
#   D75 × 4.5 mm, 171 g), speed cap 600 rpm (momentum 7.5e-3 N·m·s, 0.24 J
#   stored), minimum motor torque 8 mN·m. Re-check once friction and body
#   inertia are measured.
# - Motor selection: sets PWR-01, THM-01 and the SFT-08 current limit.
# - Measured peak battery current: sets the SFT-07 fuse rating.
